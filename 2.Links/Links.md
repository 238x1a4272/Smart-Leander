# Smart Lender – Loan Eligibility Prediction System
## Software & Python Library Resources

This document outlines the tools, environments, and libraries required to build, train, and run the Smart Lender Loan Eligibility Prediction System.

---

### Key Resources & Official Documentation

> [!NOTE]
> It is recommended to install all libraries inside a dedicated virtual environment (such as an Anaconda environment) to ensure dependency compatibility.

#### 1. Anaconda Navigator
*   **Purpose**: Manages virtual environments, installs packages, and launches tools for Data Science/ML.
*   **Usage**: Environment isolation, package management, python distribution.
*   **Link**: [Official Anaconda Download](https://www.anaconda.com/download)

#### 2. PyCharm IDE
*   **Purpose**: A full-featured IDE used for writing, debugging, and testing Python code.
*   **Usage**: Application coding, project workspace management, testing, and debugging.
*   **Link**: [JetBrains PyCharm](https://www.jetbrains.com/pycharm/)

#### 3. NumPy
*   **Purpose**: Numerical computing support, array structures, and math functions.
*   **Usage**: Matrix calculations and general data processing.
*   **Link**: [NumPy Documentation](https://numpy.org/doc/stable/)

#### 4. Pandas
*   **Purpose**: High-performance structured data analysis and manipulation.
*   **Usage**: Loading datasets, handling missing values, cleaning, and filtering features.
*   **Link**: [Pandas Documentation](https://pandas.pydata.org/docs/)

#### 5. Scikit-learn
*   **Purpose**: A robust machine learning library providing classification algorithms and model helpers.
*   **Usage**: Decison Trees, Random Forests, KNN classifiers, model evaluation, and scaling.
*   **Link**: [Scikit-learn Documentation](https://scikit-learn.org/stable/)

#### 6. Matplotlib
*   **Purpose**: Basic visualization package for plotting charts and data views.
*   **Usage**: Constructing bar charts, histograms, and scatter plots during Exploratory Data Analysis (EDA).
*   **Link**: [Matplotlib Documentation](https://matplotlib.org/stable/)

#### 7. Seaborn
*   **Purpose**: High-level statistical visualization interface with polished styling.
*   **Usage**: Drawing heatmaps, pair plots, distribution charts, and count plots.
*   **Link**: [Seaborn Documentation](https://seaborn.pydata.org/)

#### 8. Flask
*   **Purpose**: A lightweight micro web framework.
*   **Usage**: Exposing the trained machine learning model through a web page and prediction API endpoint.
*   **Link**: [Flask Documentation](https://flask.palletsprojects.com/)

### Conclusion

The Smart Lender project relies on standard, industry-grade Python tools and packages. Together, these tools form a pipeline spanning from initial **Exploratory Data Analysis (EDA)** and data cleaning, to **model training and tuning**, and finally to **deployment** in a web application.
